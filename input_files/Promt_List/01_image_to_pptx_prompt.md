# Image to PPTX プロンプト

- 作成日: 2026-05-07 00:26 JST
- 作成者: Codex (GPT-5)

## プロンプト

添付したスライド画像を、編集可能な PowerPoint 形式（pptx）で再現してください。

## 最重要

1回作って終わりにしないでください。
必ず PPTX 作成後にレンダリングして画像化し、元画像と比較してください。
崩れている箇所、位置ズレ、文字折り返し、余白の違和感を修正し、最低1回は再レンダリングしてから納品してください。

スライド全体を1枚画像として貼り付ける方法は禁止です。
テキスト、図形、カード、帯、線、アイコンを可能な限り個別要素として再現してください。

## 作業手順

1. 元画像を確認し、以下の要素に分解する
   - 背景、タイトル、メッセージボックス
   - 左カード、右カード、見出し、金額表示、箇条書き
   - 中段の水色バー、注意喚起バー、下部の結論ボックス
   - ページ番号、アイコン類、淡い背景装飾

2. 元画像のサイズと主要要素の px 座標を確認し、13.333 x 7.5 inch の PowerPoint 座標へ換算して配置する
   - 目分量だけで配置しない
   - タイトル、カード、バー、結論ボックス、ページ番号の位置・幅・高さ・余白を元画像に合わせる

3. スライドサイズは 16:9 にする
   - 13.333 x 7.5 inch
   - 元画像の縦横比に合わせ、余白が不自然に広がらないようにする

4. 各要素を、次のルールで再現する
   - テキスト：PowerPoint の編集可能なテキストボックス
   - 枠、線、帯、カード、背景装飾：PowerPoint の図形
   - アイコン、イラスト：元画像から PNG/JPEG で切り出して配置
   - SVG は使用・生成・変換しない
   - 背景画像として元画像全体を敷かない
   - 比較用レイヤーを使った場合は納品前に削除する

5. テキストを正確に転記する
   - 誤字を出さない
   - 数字、単位、句読点、全角半角、改行位置を元画像に合わせる
   - 文字が折り返されないようにテキストボックス幅を調整する
   - 金額表示はサイズ、太さ、単位位置を丁寧に合わせる
   - 箇条書きは行間、インデント、先頭記号の位置を近づける

6. 元画像からアイコン部分だけを PNG/JPEG で切り出す
   - メッセージ、目、目に斜線、書類＋円マーク、検索、メール、更新、時計、電卓、警告アイコン
   - アイコンが粗い、欠ける、低解像度で崩れる場合のみ、見た目が近い PNG/JPEG 画像を生成して補完する
   - アイコン以外のテキスト、カード、帯、背景は画像化しない

7. 色・余白・サイズを元画像に近づける
   - 濃紺の本文色、明るい青の強調色、薄い水色の帯、薄いグレーの背景
   - 角丸カード、細い罫線、右上・右下の淡い背景装飾
   - カード内余白、見出しと本文の間隔、下部結論ボックスの上下余白

8. 図形とレイヤーを整理する
   - 背景、装飾、カード、バー、罫線、アイコン、テキスト、ページ番号の順に重なりを調整する
   - テキストやアイコンが図形の背面に隠れないようにする
   - 図形は可能な限り個別に選択・編集できる状態にする

9. PPTX 作成後、必ずレンダリング画像を出力する
   - PowerPoint または LibreOffice 等で PNG または PDF に変換する
   - レンダリング画像と元画像を目視比較する
   - 可能であれば重ね合わせや差分画像も使って確認する

10. 比較時に必ず確認する
    - タイトル、メッセージ枠、左右カード、見出しアイコン、金額表示
    - 箇条書きの行間と改行位置
    - 中段バー、注意喚起バー、下部結論ボックス、ページ番号
    - 文字折り返し、全体余白の違和感

11. 崩れている場合は、修正して再レンダリングする
    - 最低1回は修正サイクルを回す
    - 文字折り返し、カード位置、金額表示、アイコン欠け、下部結論ボックス、ページ番号のズレを優先して直す
    - 明らかに崩れている状態で納品しない

12. 最後に PPTX 内部を確認する
    - SVG ファイルが含まれていないこと
    - `ppt/media` 内に `.svg` が存在しないこと
    - スライド全体を背景画像化していないこと
    - 巨大な1枚画像だけで構成されていないこと
    - テキストが PowerPoint 上で編集できること
    - 図形が個別に選択できること
    - アイコン類のみ PNG/JPEG 画像として配置されていること

## 納品時の検収結果

納品時に簡単な検収結果を報告してください。

- レンダリングして元画像と比較したこと
- 最低1回修正サイクルを実施したこと
- 修正した主な箇所
- SVG なし確認
- 1枚画像化していない確認
- 主要テキスト編集可能確認

## 納品物

- 編集可能な pptx ファイル
- レンダリング確認後の状態
- SVG なし
- 1枚画像化なし
- テキスト編集可能
- 図形編集可能
- アイコン類は PNG/JPEG
- 元画像と見比べて大きな崩れがない状態
